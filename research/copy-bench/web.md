### 공통 패턴 (커뮤니티 4곳)

1. **말투가 두 층**: 스토어 · 랜딩은 해요체 권유 + 느낌표, 고객센터는 소모임 · 프립이 합니다체로 굳고 당근 · 문토는 해요체 유지. 스토어부터 운영정책까지 **해요체 하나로 가는 곳은 당근뿐** → 동행자 · 길잡이에게 같은 말투를 쓰는 우리에게 기준점.
2. **첫 줄과 신뢰 장치**: 소모임 · 문토 · 프립은 첫 단락에 규모 · 순위 숫자. 당근만 장소어(동네 · 이웃 · 근처)로 시작. 신뢰 지표는 점수 · 레벨(매너온도 · 매너점수 · 모임 레벨) → 우리는 순위 · 레벨이 비목표라 **장소어 + 행동(완주 · 지도)** 첫 줄과, 점수 대신 "본인인증한 길잡이"로 안심시키는 문구가 필요.
3. **어휘 경계 근거**: 연애 맥락 낱말(N-03 금지어)과 데이팅 앱 나열(문토), 대면을 뜻하는 동사 반복(소모임)이 있다 → 우리 금지어 유지 근거. 걷다 · 달리다 · 완주하다 같은 **활동 동사 중심**이 차별점.
4. **도움말 제목은 질문형 다수**(~나요? / ~하나요?) + 사용자 목소리 서술(~하고 싶어요). [멤버] · [호스트] 머리표처럼 [동행자] · [길잡이]로 가를 수 있음.
5. **답변 뼈대**: 결론 1문장 → 경로 "A > B > C" → 주의 → 연락처. 취소 · 환불은 "조건: 결과" + 기준 시점. 넷 모두 평일 · 당일 같은 상대어를 자유롭게 쓰고 요일 괄호 · 화살표 범위를 고정한 곳은 없음 → **우리 표기 규칙이 더 엄격하고 그 자체가 차별점**.
6. **불참은 벌칙과 돈으로**: 당근은 금지 항목 + 약속 요청, 문토 · 프립은 환불 불가 구간 · 인원 미달 자동 취소. 읽은 범위에서 **늦음 · 불참을 미리 알리게 돕는 안내는 없음** → 대화방 늦음 · 불참 알림을 "강요보다 계기"로 설명할 여지.

- **공식 소개문**: 히어로는 "브랜드명 + 쉼표 + '-다' 기본형" 한 줄(15자) 아래 "~게!"로 끝나는 짧은 3줄. 섹션 제목에 반말 되묻기 · 영어 문장 · 느낌표가 섞이고, 본문은 합니다체 · 해요체, "여러분" · "당신"이 섞임. 숫자는 다운로드 · 이용자 지표 카드(사용자보다 제휴 상대를 향함).
- **고객센터 안내문**: 공개 도움말이 없어 스토어 본문의 고지가 그 역할. 구독 해지는 경로를 ">"로 잇고 버튼 이름은 [ ]. **권한 고지 순서가 고정**: [선택] · [필수] 구분 → "권한 이름: ~할 때 필요" 목록 → 선택 권한은 거부해도 이용 가능 → 철회 경로. 위치 정보 목적은 운동 위치 · 이동 경로 표시.
- **기록 · 경쟁 · 동기**: 중심 낱말은 완주 · 함께 · 응원. 페이스 · 순위 · 랭킹 0회. 경쟁은 가상 러너 정도로 약함. 응원을 놓쳐도 괜찮다는 완충 문장, 음성 응원 욕설 차단 안내. 다만 "도전 · 정복" 같은 낱말은 자주 씀. 동기 장치는 옆에서 같이 달려 주는 트레이너라는 동행 비유.
- **눈에 띄는 규칙**: 고민을 사용자 말로 먼저 보이고 앱이 답하는 문답 구조. 고지문은 목적 → 거부 가능 → 철회 순서. 채널마다 말투가 다름. 홈은 달리기를 혼자의 쓸쓸함(N-03 금지어 계열)으로 규정한 뒤 뒤집는 프레임.

### 공통 패턴 (러닝 앱 3곳)

1. **스토어 뼈대가 같다**: 한 줄 정의 → 대상 포괄(초보부터 마라톤까지) → 기능 묶음(명사형 소제목 + 짧은 설명) → 구독 · 권한 · 고객센터 고지. 감성 문장은 도입과 마무리에만, 이모지는 셋 다 0.
2. **어미마다 맡는 일**: 권유 · 제목은 "-해 보세요 / -세요", 기능 설명은 합니다체, 목록 항목은 명사형, 고지문은 합니다체 계약문, **해요체는 브랜드 목소리(동행 약속 · 쉬어도 된다는 허락)**.
3. **도움말 제목 표준**: 사용자 질문을 1인칭으로 옮긴 질문형. 답은 정상 상태 → (공감) → 기기별 단계 → 안 되면 문의.
4. **수치 · 경쟁 강도**: 스트라바(리더보드 · 구간 · 기록 경신) > 나이키(기록 · 배지 · 스트릭, "숫자가 전부는 아니다"로 완충) > 런데이(완주 · 코치 동행, 순위 0). 셋 다 기록 옆에 "응원".
5. **빌려올 것**: 1인칭 질문형 도움말 제목 · 정상 1문장 → 공감 1문장 → 단계 → 문의 순서 · 권한 고지 4요소(목적 · 필수/선택 · 거부 가능 · 철회 경로) · **오늘 쉬어도 괜찮다는 허락 문장**(원칙 3과 맞음) · 출발 · 종료 지점 숨기기처럼 위치 프라이버시를 기능으로 앞에 두기(동네 지도 앱이라 더 중요) · 기록 계산이 바뀌면 먼저 알리기 · "완주" 중심 어휘.
6. **피할 것**: 리더보드 · 구간 경쟁 · 기록 경신을 명령하는 문장, 연속 기록 축하(MANUAL 비목표), 기록 절대화, 운동을 혼자의 쓸쓸함으로 규정하는 프레임(N-03 금지어 계열), 오프라인 대면을 권하는 문장(N-03 금지어 계열), 규모 숫자 자랑, 채널마다 바뀌는 호칭(여러분 · 당신), 검색어 반복으로 늘린 설명.

## 공통 결론 (8곳 + 토스 원칙 → 우리에게)

1. **말투 하나**: 제품 안은 해요체 하나(토스 · 당근). 합니다체는 회사 비전 · 법적 고지 같은 다른 층에만(토스) → 우리 보드의 섹션 도입 합니다체는 "다른 층"으로 둘지 헤드 결정.
2. **버튼은 다음 화면을 말한다**: 버튼 · CTA는 "~하기 · ~ 보기" 꼴, 누른 뒤를 예상하게(토스 예상되는 힌트). 빠져나가는 버튼은 "닫기"(토스) → 우리는 "신청 취소"가 실제 기능이라 더 중요.
3. **완료는 수고와 지도를 말한다**: 끝낸 순간엔 숫자보다 수고(토스 숨은 감정 찾기) · 완주 중심 어휘(런데이) → 우리 완주 문구 방향과 같음. 기록 경쟁 · 연속 기록 축하는 피함(스트라바 · 나이키).
4. **거절 · 에러는 사실 + 대안 + 버튼 하나**: "~는 어려워요 + 대신 ~할 수 있어요"(토스), 상황 · 이유 · 해결(토스 에러 6원칙).
5. **도움말 · 안내는 결론 먼저**: 질문형 1인칭 제목 → 결론 1문장 → 경로 → 조건 → 연락(커뮤니티 4곳 · 러닝 3곳 · 토스 공통). 권한 고지 4요소(러닝 앱).
6. **허락하는 말**: 오늘 쉬어도 괜찮다(나이키), 강요 대신 제안(토스) → 원칙 3 "강요보다 계기"와 맞음.
7. **우리 규칙이 더 엄격한 곳**: 날짜 · 시각 절대 표기, 상대 시간 금지는 조사한 9곳 어디에도 없다(모두 평일 · 당일 같은 상대어를 씀) → 차별점으로 유지.
8. **피할 것**: 규모 · 순위 숫자 첫 줄(소모임 · 문토 · 프립), 느낌표 · 이모지 장식, 연애 맥락 낱말(N-03), 운동을 혼자의 쓸쓸함으로 규정하는 프레임, 기록 절대화, 채널마다 바뀌는 호칭.
