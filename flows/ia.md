## 1. 내비게이션

하단 탭 4: **찾기** · **지도** · **채팅** · **나**. 현재 탭은 `text` 색 + 라벨, 나머지 `text-muted`. 채팅 탭은 안 읽은 메시지 수 배지. 탭 밖 화면(B·H·J 등)에서는 들어온 탭을 선택색으로만 표시한다(스크린 리더의 "현재 페이지"는 탭 첫 화면에서만).
상단 바(탭 첫 화면): A = 왼쪽 동네 선택(📍마포구 ⌄ → A-1) · 오른쪽 검색(K)·알림(J)·회차 열기(E) / D = 제목 · 공개 범위(G-2)·알림 / I·G = 제목 · 알림. 새 알림이 있으면 알림 아이콘에 점.
상단 바(그 밖): 왼쪽 뒤로 / 가운데 제목 / 오른쪽은 화면별 1개 — B·C·H는 **신고**(F-08), J는 설정 아이콘(→ G-2), G-1은 없음(저장은 주 버튼).
회차 상세(B)는 신청했거나 내가 여는 회차일 때 **정보 · 대화** 두 탭을 가진다. 대화(H)는 B 안의 탭이라 깊이가 늘지 않는다.
깊이: 탭(1) → 상세(2, B의 정보·대화 포함 · J 알림 · K 검색) → 시트(3). J·K에서 여는 B·C는 같은 2단계 화면으로 옆 이동이다. 3단계를 넘는 화면 없음. 모든 화면에 뒤로 또는 탭이 있어 막다른 화면 없음.
