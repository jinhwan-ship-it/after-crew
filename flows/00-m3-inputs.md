# M3 입력 — 헤드 결정 (2026-09-29, 인터뷰 전)

MANUAL v1.1이 침묵하는 지점에 대한 헤드 결정. 매뉴얼 개정 아님 → STATUS 잠금 후 결정에 기록, 다음 해제 때 §11 병합. M3 플로우·IA는 이 세 가지를 전제로 그린다.

## D-M3-01 · A 모임 찾기의 빈 상태 (05-questions 피드백 1)
- 동네에 회차가 0개인 날: "지금 열린 모임이 없어요"를 숨기지 않고 보여준다
- 당겨서 새로고침(pull-to-refresh)은 기본 인터랙션
- **근처 동네의 모임을 추천**한다 (동네 반경 확장 — 반경·개수는 M3에서 값으로)
- 참조: F-01 · 원칙 2(수치보다 지도: 빈 상태에서도 지도의 코스는 보인다)

## D-M3-02 · 완주 판정 (05-questions 피드백 3)
- **완주 = 체크인 + 해산.** 이동 기록(F-05)은 부가 데이터이며 완주 판정에 쓰지 않는다
- 따라서 GPS·네트워크가 끊겨도 체크인·해산이 있으면 완주, 지도(D)에 코스가 채워진다. 기록이 끊긴 구간은 지도에 "기록 없음"으로 남기지 않고 코스 자체(길잡이가 설정한 코스 선)를 채운다
- 참조: F-04 · F-05 · F-06 · 원칙 1(경쟁보다 완주)

## D-M3-03 · 코스의 출처와 역탐색 (05-questions 피드백 4)
- **코스는 길잡이가 설정한다** (개설 시 출발·해산 지점 + 경로)
- 개설 시 **다른 길잡이가 만든 기존 코스를 추천받아 그대로 쓸 수 있다** → 코스가 회차와 별개로 쌓이는 "코스 라이브러리"가 생긴다
- 동행자 D(내 동네 지도)의 미완주 코스 = 길잡이들이 만든 코스. 코스를 누르면 그 코스로 열린 회차가 있으면 보인다(SC-2 #1 유지). 열린 회차가 없으면 코스 정보만
- 참조: F-07 · F-06 · F-01 · SC-2 #1 · SC-3 #2

## D-M3-04 · 취소 시한과 길잡이 미도착 (H-20·H-21, 헤드 확정 2026-09-29)
- 동행자 본인 취소: 출발 전까지 언제든, 마감 없음. 취소하면 자리가 바로 다시 열린다
- 길잡이 회차 취소: 출발 전까지 언제든, 전원 즉시 알림. 출발 3시간 이내 취소는 "곧 출발이에요, 동행자 N명에게 바로 알림이 가요"를 한 번 더 확인
- 길잡이 미도착: 출발 시각 +15분까지 길잡이 체크인이 없으면 자동 취소 + 전원 알림

## D-M3-07 · 날짜·시간 표기와 찾기 기본값 (H-10, 헤드 결정 — "평일·주말" 같은 상대 표현 금지)
- 회차의 날짜·시간은 항상 **정확한 요일·날짜·시각**으로 쓴다: "9/30 (화) 19:30 → 20:10". "오늘 저녁"·"이번 주말"·"평일" 같은 표현은 필터 이름·카드·알림 어디에도 쓰지 않는다
- A 찾기 기본값: 오는 7일의 회차를 **날짜별로 묶어** 보여준다(날짜 헤더 "9/30 (화)"). 상단 날짜 스트립(7일, 요일+날짜)으로 하루를 고르면 그날만. 활동 칩은 그대로
- 참조: F-01 · F-02

## D-M3-08 · 캘린더 플랜 (헤드 요청 2026-09-29 — 매뉴얼 미규정, F-10(안)으로 STATUS 잠금 후 결정에 기록, 다음 해제 때 §5 병합)
- 모임이 확정되면(동행자: 신청 완료 / 길잡이: 개설 완료) **그 날짜에 플랜이 만들어진다**
- **기기 캘린더만** (헤드 정정 2026-09-29): 신청 완료 상태(B)와 개설 완료 시트에 "내 캘린더에 추가" — 제목=회차명, 시간=출발→해산, 장소=출발 지점, 메모=코스·거리, 알림 1시간 전. 백엔드 없이 .ics
- 앱 안 달력 화면은 만들지 않는다. 나 탭에는 신청·개설 내역 목록만(날짜 명시)
- 취소 시: 취소 알림에 "캘린더에서 삭제" 안내(자동 삭제 불가)
